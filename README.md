# ミノスピードドロップ (Mino Speed Drop)

テトリスの「フィネス(Finesse)」— 最少手数でミノを正確に配置する技術 — を練習するための、ブラウザだけで動くトレーニングゲームです。

🔗 **プレイはこちら**: https://tottori007.github.io/msd/

---

## 概要

ランダムに提示される目標(ターゲット)の位置に、表示されたミノを**最短手数**で配置していく一人用のトレーニングゲームです。7種類のミノ(I, O, T, S, Z, J, L)を1セットとした「7-bag」を3周、合計21個のミノを1セッションとして遊びます。

- 各ミノには壁への押し付け・壁蹴り(Wall Kick)・DAS切り返し(DAS Tapback)などを使った最短の操作手順が存在し、ゲーム側がBFSで理論値を自動計算します。
- 最短手数を超えて配置してしまうと、その場でセッションが終了(MISS)します。
- 21個すべてを最短手数で配置しきるとクリアです。

## 主な機能

- **Finesse Guide(操作手順ガイド)**: ON にすると、各ミノの最短手数と実際の操作手順(移動・回転・ハードドロップ)をアイコンで表示します。OFF でも最短手数の判定自体は行われます。
- **Next キュー + 先読みプレビュー**: 次に出てくるミノの目標位置も、あらかじめ薄く盤面に表示されます。
- **ゴーストピース**: 現在操作中のミノをハードドロップした場合の着地位置をプレビュー表示します。
- **Hold(ホールド)**: ミノを1つだけ保留して後で使えます。
- **一時停止**: プレイ中に Esc キー、またはヒントバーのボタンでいつでも一時停止できます。
- **MISS ポップアップ**: 配置ミス・最短手数オーバーが発生した瞬間にセッションが終了し、原因・最短手数・正しい操作手順(Finesse Route)を確認できます。
- **リザルト画面 / X(旧Twitter)シェア**: クリアタイムを添えて結果をポストできます。
- **日本語 / English 切り替え**: 右上のボタンでいつでも切り替え可能。初回はブラウザの言語設定から自動判定されます。
- **PC・スマホ両対応**: PC はキーボード操作、スマホはオンスクリーンボタン(誤操作防止のレイアウト調整済み)に対応したレスポンシブ UI です。

## 操作方法

| 操作 | キー |
|---|---|
| 左移動 / 右移動 | ← → または A D |
| ソフトドロップ | ↓ または S |
| ハードドロップ | ↑ または W |
| 回転(左 / 右) | Z, , / X, . |
| ホールド | Space |
| 一時停止 | Esc |
| はじめに(遊び方) | H(タイトル画面) |
| リトライ | R(一時停止中・MISS時・リザルト画面) |
| タイトルへ | Esc(一時停止中・MISS時) |

スマートフォンではオンスクリーンの方向ボタン・回転タップゾーン・ハードドロップ/ホールドボタンを使用します。

## 技術構成

- **単一の HTML ファイル**(`index.html` 1本)に HTML / CSS / JavaScript をすべて内包。ビルド不要で、ダウンロードしてブラウザで開くだけで動作します。
- 外部ライブラリへの依存なし(バニラ JavaScript)。
- ミノの最短手数・最短操作手順は BFS(幅優先探索)による自己実装のソルバーで算出しています(SRS 準拠の回転・壁蹴りを考慮)。
- 盤面描画は `<canvas>` を使用。
- X(Twitter)シェアは `twitter.com/intent/tweet` への直リンクで実装(外部スクリプト読み込みなし)。
